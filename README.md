# 輸入振替 月次処理ツール

毎月の「輸入商品 各院経費 → 法人間振替の奉行流し込み」作業を自動化します。

## 手作業だったこと

```
① C:\Users\<自分>\Box\横浜経理部\内部関係
     \1_日)■■奉行 流し込み、各種作業□□
       \★☆せるふばんく各種振込作業【新宿･横浜】、法人間振替請求書
         \2026年09月処理\請求書\根拠ﾃﾞｰﾀ\医療法人\法人間処理データ（ｺﾋﾟｰ）
           \☆入力用輸入商品2026年8月各院経費.xlsm

② C:\Users\<自分>\Box\横浜経理部\内部関係
     \14_バクラク\請求書発行\法人間\法人間_個別流し込みCSV\輸入振替
       \輸入振替_樹慶会流し込み用CSV.csv
```

1. ① を開いて B 列を「樹慶会」でフィルタ
2. ② へ貼り付け（C列→C列 / D列→D列 / F列→G列およびL列）、日付は処理日の前月末日
3. ② を勘定奉行へ流し込み

## 自動化できる範囲

| 工程 | 自動化 | このツール |
| --- | --- | --- |
| ①②のフォルダ／ブックを開く | **完全** | `1` `2` `6` のバッチ |
| 「商品ごと」→「新TWE」の集計 | **検算のみ** | 集計し直して照合。値の書き戻しは人（下記） |
| 1. B列を法人で絞る | **完全** | ブックを直接読んで抽出 |
| 2. ②へ転記・日付を入れる | **完全** | ② を生成して上書き（検算・退避つき） |
| 検算（合計照合・前月比較） | **完全** | 手作業では未実施だった確認を毎回自動で実行 |
| 3. 勘定奉行へ流し込み | **手作業** | ② を所定の場所に置くところまで。取込操作は人 |
| ① のブック自体を作る | 対象外 | 「商品ごと」の元になる取込データは上流の別処理 |

**「商品ごと」→「新TWE」について**：① の 新TWE の E 列は数式ではなく、
明細シート「商品ごと」を (医院ID, 勘定科目ID) で集計した値を貼り付けたものです。
ツールは毎回この集計を再現して新TWE と突き合わせ、食い違えば
「貼り直しが済んでいない可能性」として警告します（2026年8月分は 506 行すべて一致）。
新TWE への書き戻し自体は、ブックの他の用途に影響するため行いません。

**3 を自動化していない理由**：奉行の取込は仕訳が確定する操作なので、人の確認を挟む設計にしています。
② は常に同じ場所・同じ名前・同じレイアウトで出力されるため、奉行側で取込パターンを保存しておけば数クリックで終わります。

**このツールは自分の PC で動きます。** チャットから起動する仕組みではありません。
毎月の実行はバッチのダブルクリックです。

**書き込むのは ② の 1 ファイルだけです。**
① は zip として読むだけで、一切変更しません。
② は上書き前に `_backup\` へコピーを残します。

## 使い方

### 準備（最初の 1 回だけ）

このフォルダ一式を消えない場所に置き（例：`C:\Users\<自分>\Documents\経理ツール`）、
`0_デスクトップにショートカットを作る.bat` をダブルクリック。
デスクトップに 4 つのアイコンができます。

### 毎月の操作

| やりたいこと | ダブルクリックするもの |
| --- | --- |
| **まず試算する**（②は書き換えない） | `4_CSVを試算する（書き込まない）.bat` |
| **②を作成して更新する** | `5_CSVを作成して更新する.bat` |
| ① のフォルダを開く | `1_今月のフォルダを開く.bat` |
| ① のブックを開く | `2_今月の入力用ブックを開く.bat` |
| ② のフォルダを開く | `6_CSVフォルダを開く.bat` |
| パスを確認する（困ったとき） | `3_パスを確認する.bat` |
| 設定を変えた後の動作確認 | `7_設定を変えたらテストする.bat` |

年月は PC の日付から決まるので、普段は何も入力しません。
`5` は検算結果を表示したうえで「上書きしますか？ (Y/N)」と聞いてから書き込みます。

推奨の流れは **`4` で確認 → `5` で更新 → ② を奉行へ流し込み** です。

### 実行例

```
── 対象 ──────────────────────────────────────────
  処理年月 : 2026年09月処理
  データ月 : 2026年8月
  計上日   : 2026/8/31  （処理日の前月末日）
  対象法人 : 樹慶会

── 検算 ──────────────────────────────────────────
  行数 : 23 行 / 医院 8 件

    勘定科目        件数                 金額
    5501            8         31,335,785
    5502            7          4,461,984
    5503            8         36,566,614
    合計           23         72,364,383

    ブックの突合表との照合（差は切り捨ての端数。件数[円]未満なら正常）
      科目 5501  ブック 31,335,787.59  今回 31,335,785  差 2.59  OK
      科目 5502  ブック  4,461,984.00  今回  4,461,984  差 0.00  OK
      科目 5503  ブック 36,566,615.70  今回 36,566,614  差 1.70  OK

  前回 :   23 行  合計  72,364,383
  今回 :   23 行  合計  72,364,383   （増減 0）
```

### 別の月・別の法人

```
5_CSVを作成して更新する.bat 202610      2026年10月処理
5_CSVを作成して更新する.bat -1          先月

powershell -File scripts\New-YunyuFurikaeCsv.ps1 -Corporation 孝和会 -DryRun
```

`-Corporation` を変えれば、②のファイル名が `輸入振替_<法人>流し込み用CSV.csv` の規則に従う限り
他法人でもそのまま使えます。

## 手作業より安全になる点

- **転記ミスが起きない** — オートフィルの引きずりや貼り付け位置のずれが構造的に発生しません。
  （いただいた前回の②では、末尾 5 行が上の行と同じ 13,784,892 になっていました）
- **毎回検算する** — 科目別合計をブックの突合表と自動照合し、切り捨ての端数を超えたら警告します。
- **集計の貼り直し漏れに気づける** — 明細「商品ごと」を集計し直して 新TWE と突き合わせます。
- **前月と比較する** — 行数・合計の増減と、医院の追加／廃止を毎回表示します。
- **上書き前に退避する** — ② の直前の内容を `_backup\輸入振替_..._YYYYMMDD_HHmmss.csv` に残します。
- **二重処理に気づける** — ② に同じ計上日の行が既にある場合に警告します。
- **書式が常に一定** — Shift_JIS / CRLF / 13 列 / 先頭行のみ `*`。奉行の取込仕様に毎回そろいます。

## 前提

このツールは次を前提にしています。変わったら `scripts\Common.ps1` の設定を直してください。

- ① のシート名は `新TWE`、3 行目からデータ、A=医院 / B=法人 / C=医院ID / D=勘定科目ID / E=金額
- 小計（① F列）は `ROUNDDOWN(E,0)` — ツールは E から作り直し、ブックの F と食い違えば警告します
- ② の固定値は CSJS202=901 / CSJS206=2 / CSJS300=0 / CSJS301=171 / CSJS302=2 / CSJS306=2、
  摘要は `SBC商品 科目振替`（末尾の半角スペース 2 つを含む）
- 処理年月とデータ月は 1 か月ずれ、計上日はデータ月の末日

Excel は起動しません（ブックを zip として直接読みます）。① を開いたままでも動きます。

## うまく動かないとき

**「〇〇が見つかりませんでした」** — 見つかった一番深い階層までは開くので、そこから手で潜れば作業は止まりません。
月フォルダが未作成なだけのことが多いです。それ以外の階層なら、誰かがフォルダ名を変えた可能性があります。
`3_パスを確認する.bat` で、想定パスと実際に見つかった階層の両方を確認できます。

なお `根拠ﾃﾞｰﾀ`（半角）と `根拠データ`（全角）、`（ｺﾋﾟｰ）` と `(ｺﾋﾟｰ)` のような**表記ゆれは自動で吸収**します。
ただし `2026年10月処理` と `2026年12月処理` のような**数字を含む名前は取り違えを防ぐため厳密に照合**し、
無ければ「無い」と報告します。

**「② に書き込めませんでした」** — ② を Excel で開いたままにしていないか確認してください。

**「上書き先の候補が N 件あり…」** — ②のフォルダに紛らわしい名前の CSV が複数あります。
候補が一覧表示されるので、`-DestinationFile "<フルパス>"` で指定して実行してください。
勝手にどれかを選んで上書きすることはしません。

なお②のファイル名は `輸入振替_樹慶会流し込み用CSV.csv` を正式名として扱いますが、
それが無ければ `輸入振替*樹慶会*CSV*.csv` に合う CSV を探します
（「流し込み用CSV」／「流し込みCSV」のような表記のゆれを拾うため）。
1 件に絞れたときだけ、警告つきでそこへ書き込みます。

**「Box フォルダが見つかりませんでした」** — Box Drive が起動していないか、`%USERPROFILE%\Box` 以外にあります。
`scripts\Common.ps1` の `BoxRootCandidates` に実際の場所を足してください。

## 設定の変え方

変更が要るのは `scripts\Common.ps1` の「設定 ここから／ここまで」だけです。
直したら `7_設定を変えたらテストする.bat` で確認してください。

| 設定 | 意味 |
| --- | --- |
| `BoxRootCandidates` | Box のルート候補 |
| `Source.SegmentsBeforeMonth` / `SegmentsAfterMonth` | ① のフォルダ階層 |
| `Source.MonthFolderFormat` / `WorkbookNameFormat` | ① の月フォルダ名・ブック名の形 |
| `Source.SheetName` / `Column*` | ① の読み取り位置 |
| `Source.Detail*` | 明細シート「商品ごと」の読み取り位置 |
| `Destination.Segments` / `FileNameFormat` | ② の場所とファイル名 |
| `Destination.Header` / `CSJS*` / `Summary` | ② の固定値 |
| `DataMonthOffset` | 処理年月とデータ月の差（既定 `-1`） |
| `Corporation` | 既定の対象法人（既定 `樹慶会`） |

## 動作確認について

`tests\Test-KeiriTools.ps1` が、モックの Box ツリーを作って 29 項目を検証します
（パス解決・表記ゆれ・年月解釈・CSV の書式・ブックとの突合・明細再集計・二重実行・退避・`-DryRun`）。
実物の 2026年8月ブックを入力に **29 件すべて成功**しています。

テストは実際の Box には一切触れません。テンポラリに偽の Box ツリーを組み立て、
そこへ向けてスクリプトを動かしています。

ただし **Windows 実機・実際の Box 上では未検証**です。初回は必ず
`3_パスを確認する.bat` でパスを確認し、`4_CSVを試算する（書き込まない）.bat` で
中身を見てから `5` を実行してください。
