# 横浜経理部 月次フォルダ ワンクリックオープナー

Box の深い階層を毎月手で潜らずに、その月の
**「法人間処理データ（ｺﾋﾟｰ）」フォルダ**と
**「☆入力用輸入商品YYYY年M月各院経費.xlsm」**を一発で開くための道具です。

## 対象のパス

```
%USERPROFILE%\Box
  └ 横浜経理部
     └ 内部関係
        └ 1_日)■■奉行 流し込み、各種作業□□
           └ ★☆せるふばんく各種振込作業【新宿･横浜】、法人間振替請求書
              └ 2026年09月処理          ← ここだけ毎月変わる
                 └ 請求書
                    └ 根拠ﾃﾞｰﾀ
                       └ 医療法人
                          └ 法人間処理データ（ｺﾋﾟｰ）
                             └ ☆入力用輸入商品2026年8月各院経費.xlsm
```

**処理年月とデータ月は 1 か月ずれます。**
`2026年09月処理` フォルダの中身は `2026年8月` のデータ、という前提で組んでいます
（フォルダ名は `09` とゼロ埋め、ファイル名は `8月` とゼロ埋めなし、という違いも再現済み）。

## 使い方

### 準備（最初の 1 回だけ）

このフォルダ一式を、消えない場所に置きます（例：`C:\Users\<自分>\Documents\経理ツール`）。
そのうえで `0_デスクトップにショートカットを作る.bat` をダブルクリック。

デスクトップに 2 つのアイコンができます。

- 今月の経理フォルダを開く
- 今月の入力用ブックを開く

以後はこのアイコンをダブルクリックするだけです。

### 毎月の操作

| やりたいこと | ダブルクリックするもの |
| --- | --- |
| 今月の `法人間処理データ（ｺﾋﾟｰ）` を開く | `1_今月のフォルダを開く.bat` |
| 今月の `☆入力用輸入商品…xlsm` を開く | `2_今月の入力用ブックを開く.bat` |
| パスだけ確認する（開かない） | `3_パスを確認する.bat` |

年月は PC の日付から自動で決まるので、普段は何も入力しません。

### 別の月を開きたいとき

`.bat` にフォルダやファイルを **ドラッグ&ドロップ**……ではなく、
コマンドプロンプトから引数を渡すか、ショートカットの「リンク先」の末尾に足します。

```
1_今月のフォルダを開く.bat 202610      → 2026年10月処理
1_今月のフォルダを開く.bat 2026-10     → 同上
1_今月のフォルダを開く.bat 2026年10月  → 同上
1_今月のフォルダを開く.bat -1          → 先月（2026年08月処理）
1_今月のフォルダを開く.bat +1          → 来月
```

PowerShell から直接呼ぶこともできます。

```powershell
.\scripts\Open-KeiriMonth.ps1 -Month 202610
.\scripts\Open-KeiriMonth.ps1 -Month -1 -OpenWorkbook
.\scripts\Open-KeiriMonth.ps1 -ShowPath
```

## うまく動かないとき

### 「〇〇が見つかりませんでした」と出る

見つかった一番深い階層までは開きにいくので、そこから先は手で潜れば作業は止まりません。
そのうえで、

- **`2026年10月処理` が見つからない** → その月のフォルダがまだ作られていないだけ。
- **それ以外の階層が見つからない** → 誰かがフォルダ名を変えた可能性があります。
  `scripts\Open-KeiriMonth.ps1` の冒頭「設定 ここから」の該当行を直してください。

なお、`根拠ﾃﾞｰﾀ`（半角ｶﾀｶﾅ）が `根拠データ`（全角）になっている、
`（ｺﾋﾟｰ）` の括弧が半角になっている、といった**表記ゆれは自動で吸収**します。
`3_パスを確認する.bat` を実行すると、想定パスと実際に見つかった階層の両方が出るので、
どこでずれているかがすぐ分かります。

### 「Box フォルダが見つかりませんでした」と出る

Box Drive が起動していないか、Box が `%USERPROFILE%\Box` 以外にあります。
`scripts\Open-KeiriMonth.ps1` の `$BoxRootCandidates` に実際の場所を足してください。

### ブックが開かず、フォルダだけ開く

その月の `☆入力用輸入商品YYYY年M月各院経費.xlsm` が無い場合です。
名前違いの `☆入力用輸入商品*各院経費.xls*` があれば、更新日時が一番新しいものを開きます
（Excel が作る `~$` 付きの一時ファイルは無視します）。

## 設定の変え方

変更が要るのは `scripts\Open-KeiriMonth.ps1` の冒頭「設定 ここから／ここまで」だけです。

| 設定 | 意味 |
| --- | --- |
| `$BoxRootCandidates` | Box のルート候補（上から順に探す） |
| `$SegmentsBeforeMonth` | Box 直下から「YYYY年MM月処理」の 1 つ上まで |
| `$SegmentsAfterMonth` | 「YYYY年MM月処理」から目的地まで |
| `$MonthFolderFormat` | 月フォルダ名の形（既定 `{0}年{1:00}月処理`） |
| `$WorkbookNameFormat` | ブック名の形（既定 `☆入力用輸入商品{0}年{1}月各院経費.xlsm`） |
| `$DataMonthOffset` | 処理年月とデータ月の差。既定 `-1`（＝1 か月前） |

## 動作確認について

パス組み立て・年月の解釈・表記ゆれ吸収・フォルダやブックが無いときの
フォールバックは、モックのフォルダツリーを作って PowerShell 7 で確認済みです。
ただし **Windows 実機・実際の Box 上では未検証**なので、
最初は `3_パスを確認する.bat` でパスが合っているかを見てから使ってください。

## ファイル構成

```
0_デスクトップにショートカットを作る.bat   初回だけ実行
1_今月のフォルダを開く.bat                 毎月使う
2_今月の入力用ブックを開く.bat             毎月使う
3_パスを確認する.bat                       困ったとき
scripts/
  Open-KeiriMonth.ps1        本体（設定もここ）
  New-DesktopShortcut.ps1    ショートカット作成（-Remove で削除）
```
